## Key Architecture Facts

- **9 agents**: Alphonso, Jose, Hector, Miya, Maria, Marcus, Echo, Sentinel, Nova — all in `src/agents/`, all enforced by `agentContractService.ts`
- **policyEnforcementService.ts gates every outbound connector call**. Default fail-safe posture: missing credentials always block; Zero-Cost Mode (`zeroCostMode: true` by default) blocks paid/metered connectors; Approval Mode (`approvalMode: true` by default, changed from `false` in the 2026-08-17 security pass) blocks high-risk actions and high-risk connectors on fresh installs until the user explicitly approves or disables Approval Mode in Settings. To allow high-risk actions without per-action approval, the user must explicitly set `approvalMode: false` in Settings. Verify current defaults in `src/services/policyEnforcementService.ts` before relying on this in security-sensitive work.
- **licenseService.ts**: license tier validation (Free/Pro/Enterprise) gates premium connectors (GitHub, Slack, Claude, ChatGPT, YouTube, Notion, ClickUp, SD WebUI, ComfyUI)
- **parallelExecutionService.ts**: parallel task execution with concurrency control, retry logic, and task queues
- **cacheService.ts**: memory caching with TTL, LRU eviction, and global/connector/agent caches
- **25 connectors** (`DEFAULT_CONNECTORS` in `connectorRegistry.js`): Telegram, WhatsApp, YouTube, mobile_bridge, ChatGPT, Claude, Qwen, Notion, ClickUp, SD WebUI, ComfyUI Video, Runway, GitHub, Slack, Discord, Generic Webhook, Ollama, Brave Search, Perplexity, Tavily, DeepSeek, n8n, NVIDIA NIM, Gemini, Hermes Agents — all policy-gated, all registered centrally, all have credential input UI in ConnectorSetupPanel. NVIDIA NIM, Gemini, and Hermes Agents are deliberately excluded from `PAID_OR_METERED_CONNECTORS` in `policyEnforcementService.ts` (NVIDIA/Gemini: free-tier cloud, see `docs/superpowers/plans/2026-07-23-free-tier-cloud-providers.md`; Hermes Agents: local/self-hosted, same posture as Ollama).
- **lib.rs is ~2,024 lines** — 25 modules in src-tauri/src/ — see AGENTS.md for full module list
- **All 2555+ tests are in `src/test/`** — 186 test files; Vitest via vitest.config.js (separate from vite build config)
- **Security (Batch 1 complete)**: boot TDZ crash fixed; `gateConnectorAction` exception-safe + DSL-wired; SSRF blocking on `fetch_url_content`; `execute_command_verified` real output redaction; PKCE on all 3 OAuth scripts; clipboard/dialog/open_url use native APIs (arboard, tauri-plugin-dialog, tauri-plugin-opener); CSP narrowed to explicit ports; per-program arg allowlist in `policy_gate.rs`.
- **Two CI workflows**: `ci.yml` (lint + test + build + Tauri artifact + cargo test/clippy + npm audit + cargo audit) and `release.yml` (tag-triggered build + sign + publish).
- **`.npmrc`** has `legacy-peer-deps=true` — required because `@eslint/js@10` and `eslint@9` have a peer dep mismatch. Do not remove.
- **`eslint.config.js` covers `.ts`/`.tsx` as of 2026-07-02** (`typescript-eslint` parser/plugin, `src/**/*.{ts,tsx}` block) — previously it only covered `.js`/`.jsx` and every ".ts/.tsx" file in the repo went completely unlinted. A dedicated override block (by exact file path, not a wildcard) disables `@typescript-eslint/ban-ts-comment` for the 9 pre-existing `@ts-nocheck` files (now resolved — those component files no longer carry `@ts-nocheck`); do not widen that override list; fix `@ts-nocheck` at the source for any new file instead.
- **Multi-turn Ollama**: `generateOllamaChatStream` in `src/lib/ollama.js` uses `/api/chat` — full conversation history is passed per message. `ChatView.tsx` captures history snapshot before React state updates.
- **appendAgentActivity**: wired in `joseExecutionEngineService.ts` (`executeAssignment`) and `connectorRegistryService.js` (`appendConnectorAudit`). Activity tab now shows live data.
- **CREATE_NO_WINDOW on all Windows process spawns**: a shared `no_window()`/`no_window_async()` helper pair in `utils.rs` (`pub(crate) fn no_window(cmd: &mut std::process::Command)` / `no_window_async(cmd: &mut tokio::process::Command)`) must be applied to every `std::process::Command::new()`/`TokioCommand::new()` call site on Windows, or a visible CMD window flashes open/closed for that spawn. As of 2026-07-10 this is applied everywhere in `lib.rs`, `plugin_runtime.rs`, `voice_sidecar.rs`, `workspace.rs`, and `runtime_manager.rs` (incl. the polled `kill_pid`/`is_pid_alive` health-check helpers, which were the most likely source of *recurring* flashes since they run on every process-alive check). **CI-enforced as of 2026-09-02 (closes T14's lint half):** `scripts/verify-no-window-coverage.mjs` (`npm run verify:no-window-coverage`) scans every `.rs` file under `src-tauri/src` for an unguarded spawn site and fails the `Rust Tests & Clippy` CI job (blocking, not advisory) if one is found — a bare `Command::new("kill"|"ps"|"which")` literal is exempt since those are POSIX-only tools the flag can't apply to. `workspace.rs`'s whisper-transcription spawn was migrated off a raw inline `creation_flags(0x0800_0000)` to the shared `no_window_async()` helper as part of this pass, so the lint has one consistent pattern to check for. Apply the helper to any new spawn site — the lint will now catch it if you forget, instead of relying on memory.
- **Port map for local services** (collision caused a real P0 — see Companion/Voice OS rows below): Ollama 11434, Alphonso Bridge 4444, MCP server 3333, ComfyUI 8188, n8n 5678, Mobile Companion WebSocket **8765** (hardcoded in iOS Swift, do not change), Voice OS **8766** (moved off 8765 on 2026-07-10 due to the collision), AudioCraft 7866, Open WebUI 3001. Check this list before adding any new local service's default port.

## Before Making Changes

1. Read `docs/ALPHONSO_GROUND_TRUTH.md`
2. Check `src/services/` for an existing service before writing a new one — there are 163+ services
3. Check `src/test/` — there are 218 test files already; add to them, don't create a parallel test system
4. Run `npm run test` before and after any change; all 3,174 tests must continue to pass
5. For Rust changes, run `cargo check` AND `cargo clippy -- -D warnings` from `src-tauri/` — CI enforces `-D warnings`
6. Do not commit `.env`, `.tauri-updater-key`, or `.tauri-updater-key.pub` — they are in `.gitignore`
7. **When bumping the app version, bump all 4 locations together**: `package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, and `src-tauri/Cargo.lock`'s `app` package entry. These drifted out of sync for 9 versions (2.4.4 → 2.5.9) before this was caught by a real release build in 2026-07-02 (the published installer was mislabeled `2.4.4`) — see the "Last verified" entry below for the full story.
