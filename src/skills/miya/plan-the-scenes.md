Turn the script into a storyboard: one scene per script part, with the camera angle, the movement, and an image prompt. Give one shared style so every scene has the same look. Mark the main moments (the hook, the turning points and the call to action) with mainMoment true; they may become AI video clips. Mark with character true each scene that shows the brand's presenter or mascot (a scene with no person: false). Mark with motionSuggested true a scene where a real movement (a wave, a gesture, a dance) would help more than a camera move.
